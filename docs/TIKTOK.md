# TikTok: загрузка в черновики

Режим **inbox upload** (Content Posting API, scope `video.upload`). Сервис загружает видео в
черновики приложения TikTok, а публикуете вы сами: вставляете подпись и жмёте «Опубликовать».
Аудит приложения для этого режима не нужен, подходит для своих аккаунтов.

## Что умеет и что нет

| | |
|---|---|
| Видео 9:16, до 10 минут, MP4/MOV | да |
| Расписание, очередь, повторы, несколько брендов | да, как у Instagram |
| Подпись в TikTok | нет: API не принимает её в режиме черновиков. Текст приходит в Telegram, вставляете вручную |
| Фото-посты, первый комментарий, метка ИИ | нет |
| Комментарии, аналитика | нет (в API для обычных разработчиков недоступны) |

В очереди такая цель показывается как «TikTok · в черновиках». Статус «опубликован» значит только,
что видео доехало до черновиков.

## Настройка (один раз)

1. На developers.tiktok.com создайте приложение (Manage apps → Connect an app).
2. Добавьте продукты **Login Kit** и **Content Posting API**, scope: `user.info.basic`, `video.upload`.
3. В Login Kit укажите **Redirect URI**: `<PUBLIC_BASE_URL>/api/oauth/tiktok/callback`.
   Адрес должен быть https (сервер или туннель), точно такой, как на странице «Аккаунты».
4. Пока приложение не прошло ревью, работает **Sandbox**: добавьте свой TikTok-аккаунт в Target Users.
5. В `.env` задайте `TIKTOK_CLIENT_KEY` и `TIKTOK_CLIENT_SECRET`, перезапустите сервис и worker.
6. «Аккаунты» → **Подключить TikTok**, согласитесь на странице TikTok.

## Как работает

- Access-токен живёт 24 часа, worker сам обновляет его через refresh-токен (365 дней).
  Если refresh истёк или доступ отозван, аккаунт получает статус «нужно переподключить».
- Файл передаётся напрямую чанками (`FILE_UPLOAD`), проверка домена в кабинете TikTok не нужна.
  Видео по ссылке сначала скачивается во временный файл.
- Слишком много неопубликованных черновиков: TikTok ограничивает их число, цель уйдёт на повтор через час.
- Код: `src/publishers/tiktok.ts` (API), `src/lib/tiktokAuth.ts` (OAuth и токены),
  `src/app/api/oauth/tiktok/*` (подключение).

## Позже: прямая публикация

Когда приложение пройдёт аудит, можно добавить Direct Post (`/v2/post/publish/video/init/`,
scope `video.publish`) с подписью и приватностью, не меняя остальное устройство.
